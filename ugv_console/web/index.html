    Before the first real flight

    1. Switch the Tello on and join its Wi-Fi (TELLO-…) with this laptop.
    2. When Windows asks, allow Python on Private and Public networks (the video and status arrive that way).
    3. Fly indoors, with free space, propeller guards on, battery above 20 %.
    4. Practise with the simulated drone first, then start with Gentle.
    The drone's Wi-Fi is not the robot's: switch the laptop back to the robot's network before you use the Robot mode.

    Mission video

    The laptop films what the robot's camera sends during the mission (it starts with AUTHORIZE + SEARCH or Search from here) and saves the video when the mission is complete or stopped. Camera + YOLO must be on.

    How the search works

    1. Drive to the goal with A*.
    2. Turn on the spot in steps and hold still so YOLO can look.
    3. A confirmed green object is pinged as a survivor.
    4. The first green object seen is approached at once, also on the way to the goal.
    5. Stop at the chosen distance, face it, stand still for the chosen time: secured.
    6. Another green object known: go to it. None: mission complete.
    7. No green object yet: go to floor the camera has not seen and look again.
    STOP, link loss and localization loss pause the mission. Fix the cause, then press RESUME MISSION.
