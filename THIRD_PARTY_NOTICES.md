- UGV planner, console, bridge, maps, examples and detector: https://github.com/Aizu-x/FYP-Search-And-Rescue (then called UGV_A-Star-YOLOV5) at `e9ed19bbf93e812a4863055751381f70ab4d6e61`. Original README and credits are retained. Since 20 November 2026 the project's own code is released under the MIT License ([LICENSE](LICENSE)); that licence does not cover, and grants no additional rights to, the third-party material listed below.
- Custom ORB-SLAM3 source/assets: the team's FYP_Three_Modules_DAG_Handoff_2026-11-07 (1).zip and two frame archives. The installer preserves original source and licence files. ORB-SLAM3 and its bundled dependencies retain their own licences. Read those before distributing outside the project team.
- ERFNet (`perception/ERFNet/`): the model definition in `erfnet_tools/architecture.py` is the ERFNet code by Eduardo Romera, https://github.com/Eromera/erfnet_pytorch, licensed under the Creative Commons Attribution-NonCommercial 4.0 International licence (personal and research use). Paper: E. Romera, J. M. Álvarez, L. M. Bergasa and R. Arroyo, "ERFNet: Efficient Residual Factorized ConvNet for Real-Time Semantic Segmentation", IEEE Transactions on Intelligent Transportation Systems, 19(1), 2018. How the project trained and used it is described in `perception/ERFNet/README.md`.
- YOLOv5 (`third_party/wro_yolo/`): the detector was trained with Ultralytics YOLOv5, https://github.com/ultralytics/yolov5 (AGPL-3.0). The model files (`models/best.pt`, `models/best.onnx`) are not offered under the MIT License; check the YOLOv5 licence before reusing them.
- ORB-SLAM3 reference copy (`perception/ORB_SLAM3/`): based on https://github.com/UZ-SLAMLab/ORB_SLAM3 (GPL-3.0); its licence and the bundled libraries' notices are kept in `perception/ORB_SLAM3/source/ORB_SLAM3/`.
- `DAG_scheduler/orb_io/PROVENANCE.md` records the supplied export readers. The scheduler, adapters, tests and integration documentation were developed in the user's workspace for this project.
